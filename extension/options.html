How to use
  1. Run kai-webbridge start on this machine.
  2. Open the daemon's status page or run kai-webbridge status.
  3. Install the agent skill with kai-webbridge install-skill.
  4. Ask your agent to open a page. Tabs are grouped per task; close the group when done.

This extension can read and control every tab you open. Treat your agent as you would treat a person at your keyboard.
